# Лабораторная работа №3 - Flutter: основные элементы UI

Приложение «Мое приложение»: TabBar (Список / Сетка), ListView, GridView, Card,
Drawer, Toast (fluttertoast), навигация между экранами, ThemeData, StatefulWidget + setState().

## Запуск

```bash
flutter create flutter_lab3
# скопируйте папку lib/ из этого проекта в flutter_lab3/ (с заменой)
cd flutter_lab3
flutter pub add fluttertoast
# удалите test/widget_test.dart (он от шаблона-счётчика)
flutter run
```

Toast работает на Android, iOS и Web (в Chrome). На Windows/macOS/Linux не поддерживается.
